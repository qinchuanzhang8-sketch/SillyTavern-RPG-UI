# ST-RPG-UI · RPG 人物信息卡

> **为 SillyTavern 提供一张可拖动、可缩放、可编辑、实时填充的 RPG 人物信息卡。**

AI 每次回复时会在正文末尾输出一个【状态栏】（显示层自动隐藏，玩家看不到），扩展**边流式接收边解析**，把字段实时填进悬浮信息卡——**不需要第二次请求，不需要独立 API**。

## 主要特性（v2.0）

- **单请求方案**：状态栏随正文一次生成；显示层自动隐藏；流式填卡 + 消息到达终校。
- **模板双用**：设置面板里的「卡片模板」= 卡片显示布局 **且** 发给 AI 的填写格式，一份模板两用；字段说明（可编辑）随协议发送，指导 AI 如何填写。
- **数据连续性**：每次生成自动注入「上一张人物信息卡·内部数据」+ 连续性铁律×5，数字不再每楼乱跳；金钱只随收支增减。
- **每轮重新结算**：过时信息当次清除改写、性格与关系按当前态度重描写；怀孕/疾病等由剧情事实直接判定（上帝视角，无需医院剧情）；状态栏对剧情内所有角色（含玩家角色）不可见。
- **数值变化量（±N）**：8 项数值（好感度/体力/性欲值/高潮值/NTR值/淫荡值/敏感度）在数字后标注本次变化量，卡片上以 绿涨/红降/灰持平 显示；括号内只填数字（涨跌原因写进文字字段），显示层对旧写法同样容错。
- **数值分级 + 涨跌方向指导**：每个数值给出 0-100 分档（行为/心理/语言三维度）与"只定方向、由 AI 自行判断升降"的涨跌规则；没有触发事件写（±0）。
- **性爱记录**：💠是否处女（时间/对象/方式，失贞后不变）→ 性爱总次数（按对象累计）→ 最喜欢的阴茎 →【本次】【上次】完整复盘 → 💭比较心理 → 🍆心中最棒的阴茎是谁的。
- **性癖喜欢/不喜欢**：「🎯 性癖喜欢」「🚫 性癖不喜欢」两行分开记录（旧同行格式自动拆分）；「超级喜欢/不喜欢」带数值与剧情规则；字段说明含性癖释义、示例类型与填写铁律——处女也有幻想喜恶，两行禁止空栏；**每轮性爱结束后与所有性爱相关项一起，按这一场真实过程重新计算、更新描写（不喜欢的性癖被强制开发并高潮后可渐进迁入喜欢的行，写清转折）。**
- **精液量毫升化**：胃部/阴道内(含子宫)/肛门内/外部 分别用 ml 计；排卵后自动改显"卵子是否受精"。
- **关系显示精简**：只常驻玩家 + 一位最重要的 NTR 角色；其他角色离开或不再重要立即隐藏。
- **全卡编辑**：✎ 直接改值 / × 删除 / ＋新增；✨ 按角色卡与上下文推演补全；🗑 删角色；↺ 重置。
- **用户自定义冻结**：在设置里保存过的模板/说明默认不会被后续自动迁移覆盖（出厂文本带指纹——旧版出厂格式/说明会随版本自愈升级，多端回写后自动收敛）。
- **自动隐藏状态栏**：不依赖酒馆正则扩展，内置显示层钩子（可在设置中编辑规则）。

## 安装

1. SillyTavern → **扩展 / Extensions → Install Extension**
2. 粘贴本仓库地址：`https://github.com/qinchuanzhang8-sketch/SillyTavern-RPG-UI`
3. 安装后 **Ctrl+F5** 刷新

手动安装：把本仓库克隆到
`data/<你的用户名>/extensions/ST-RPG-UI`（推荐）或 `public/scripts/extensions/third-party/ST-RPG-UI`。

## 使用要点

- 打开扩展设置 → 「RPG 人物信息卡」开关开启；进入角色聊天后卡片自动出现。
- 「卡片模板」「字段填写说明」可完全自由编辑；点保存后即受冻结保护。
- 顶部 ⚙ 区域：拖动移卡 / ✎ 编辑 / ✨ 推演补全 / 🗑 删除角色 / ↺ 重置 / ◀▶ 切角色 / －＋ 缩放 / ▾ 折叠。

## 兼容性

- SillyTavern（开发于 1.19.x，建议较新版本）。
- **不修改任何核心文件**；卸载 = 停住酒馆、删除文件夹、重启。

## ⚠️ 内容警告（18+）

默认模板面向**成人向角色扮演**（包含 NTR 值、性爱记录、生理状态等字段与指导语）。所有文本均可在设置中完全自定义或清空。请确保你已达到所在地区的法定成年年龄。
